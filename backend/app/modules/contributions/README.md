# Contribuições fotográficas

Cada envio corresponde a uma foto. Tema e reflexão são opcionais e acompanham o registro (RF010 e RF021). Os campos de localização, data e horário devem aproveitar o EXIF disponível e permitir correção pelo participante (RF011 e RF012).

A edição carrega a imagem e os dados já existentes. O autor altera somente os campos desejados sem precisar reenviar o arquivo. Uma edição retira o registro do atlas até nova aprovação (RF014). A exclusão pelo autor ou a retirada pela administração deve repercutir na galeria, no mapa e nos percursos (RF015, RNF011).
